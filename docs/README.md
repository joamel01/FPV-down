# Dokumentindex

Läs de dokument som den aktuella uppgiften behöver. Ersätt hakparenteserna när ett
dokument tas i bruk; mallarnas innehåll är inte verifierade projektfakta.

| Dokument | Äger / läs när |
| --- | --- |
| [Krav](krav.md) | Detaljerade krav, avgränsning och acceptanskriterier. |
| [Lösning](losning.md) | Tekniska vägval, komponenter, beroenden och äldre beslutshistorik. |
| [Verifiering](verifiering.md) | Kontrollplan, genomförda kontroller och belägg. |

Aktiva dokument i `docs/` behåller fasta filnamn. Uppdatera versionsnummer och
ändringslogg vid sakändringar eller leveranser (inte vid mindre redaktionella
justeringar), samt vid kopiering till `../leverans/` eller `../arkiv/`.
Korta sammanfattningar, styrande beslut och nästa steg finns i ../STATUS.md.
Lägg till relevanta dokument här när projektet växer. Hänvisa till original i
../underlag/ i stället för att kopiera deras innehåll till flera dokument.
